# Smart Parking IoT System

Sistema de gestión de estacionamiento inteligente que utiliza ESP32, sensores infrarrojos y Firebase.

## Características
- Monitoreo en tiempo real de 10 espacios.
- Control de acceso (barreras de entrada/salida).
- Panel administrativo con reportes financieros.
- App cliente para registro y pagos.

## Tecnologías
- **Frontend:** React + Vite + Tailwind CSS
- **Backend:** Firebase Realtime Database
- **Hardware:** ESP32 (C++)

## Instalación
1. Clonar el repositorio.
2. `npm install`
3. `npm run dev`
